# Chrono Deception
⚠️ School project prototype. Unpolished, and some features may be rough or unfinished.

A top-down action RPG made by **A.K.A OWLS STUDIO** for our school course **TUJ CIS-3100**.

Fight enemies, collect weapons, and explore dangerous dungeons. Each level gets harder. Upgrade your gear and solve the mystery of the **Chrono Gate** before time runs out.

🎮 **Play it on itch.io:** https://myztyn.itch.io/chrono-deception

## Features

- Top-down action combat
- Enemies placed randomly (procedurally), so every run feels different
- Weapons to collect and a loadout to upgrade
- Dungeon levels that get harder as you go
- A story about the mysterious Chrono Gate and a time limit

## Built with

- **C++** with **SFML** 
- Free pixel art, AI images and audio assets (see Credits)
